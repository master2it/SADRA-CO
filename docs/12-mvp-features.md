## 12.1 قابلیت‌های "Must-Have" برای MVP حرفه‌ای

| # | قابلیت | توضیح | ارزش برای مشتری |
|---|--------|-------|----------------|
| 1 | **نمایش فوری نرخ** | بدون ثبت درخواست، نرخ‌ها را ببیند | حذف انتظار، تجربه Amazon-like |
| 2 | **مقایسه چند Provider** | جدول مقایسه قیمت/زمان/امتیاز | تصمیم‌گیری آگاهانه |
| 3 | **نقشه تعاملی مسیر** | نمایش مسیر با کشورها و مرزها | شفافیت + جذابیت بصری |
| 4 | **چندزبانه (FA/EN/AR/ZH)** | برای بازار بین‌المللی | جذب مشتری خارجی |
| 5 | **چندارزی (IRR/USD/EUR/CNY)** | نمایش قیمت به ارز دلخواه | راحتی مشتری بین‌المللی |
| 6 | **محاسبه‌گر آنلاین هزینه** | ورودی: مبدا، مقصد، وزن → خروجی: قیمت تقریبی | ابزار رایگان = جذب لید |
| 7 | **صفحات مسیر غنی از محتوا** | هر مسیر = یک صفحه SEO قوی | جذب ارگانیک از گوگل |
| 8 | **نشان‌های اعتماد** | "تایید شده"، "۱۰۰+ سفر"، "پاسخ سریع" | اعتمادسازی |
| 9 | **پشتیبانی چت زنده** | Crisp یا Tawk.to | کاهش نرخ خروج |
| 10 | **خروجی PDF از پیش‌فاکتور** | مشتری بتواند پرینت بگیرد | حرفه‌ای بودن |
| 11 | **CRM — مدیریت Lead** | هیچ مشتری گم نشود، Pipeline فروش | صفر Lead از دست‌رفته |
| 12 | **SRM — نرخ خودکار Provider** | بدون تماس دستی اپراتور | مقیاس‌پذیری |
| 13 | **دستیار AI** | چت + پیش‌فاکتور + handoff | جایگزینی ۷۰٪ کار اپراتور |
| 14 | **کاتالوگ محصولات** | مشاهده اجناس + پیش‌فاکتور | خودخدمتی مشتری |
| 15 | **سفارش تولید سفارشی** | محصول ناموجود → تولید در کارخانه | انعطاف کسب‌وکار |
| 16 | **پیش‌فاکتور اختصاصی ادمین** | فقط پیش‌فاکتور به مشتری | B2B اختصاصی |

### P1 Features — Technical Specs

#### 11. Price Lock
```sql
CREATE TABLE price_locks (
  id UUID PRIMARY KEY,
  rate_id UUID REFERENCES rate_boards(id),
  shipper_id UUID REFERENCES shipper_profiles(id),
  locked_price DECIMAL(15,2),
  locked_currency currency,
  expires_at TIMESTAMPTZ,  -- 48 hours from creation
  status VARCHAR(20) DEFAULT 'active'
);
```

#### 12. Rate Alert
```sql
CREATE TABLE rate_alerts (
  id UUID PRIMARY KEY,
  shipper_id UUID REFERENCES shipper_profiles(id),
  origin_country VARCHAR(100),
  destination_country VARCHAR(100),
  target_price DECIMAL(15,2),
  currency currency,
  is_active BOOLEAN DEFAULT true
);
-- Cron job: check daily, send notification if rate drops below target
```
