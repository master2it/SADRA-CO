## 2.1 وضعیت فعلی (As-Is)

> **نکته کلیدی:** در حال حاضر **همه بخش‌های بازرگانی به صورت دستی و کاغذی** انجام می‌شود و هدف پروژه، سیستمی‌سازی کامل این فرآیندهاست.

### فرآیند فعلی — حمل و نرخ‌گذاری

```
مشتری → ثبت درخواست → اپراتور → تماس دستی با Providerها
     → جمع‌آوری نرخ‌ها → ثبت دستی در سایت → مشتری انتخاب می‌کند
```

### فرآیند فعلی — بازرگانی (CRM/SRM)

```
مشتری از کانال ورودی (شبکه اجتماعی / معرفی / نمایشگاه / تماس تلفنی)
     ↓
تماس با شرکت — بدون ثبت سیستمی (یادداشت کاغذی / اکسل / حافظه اپراتور)
     ↓
اپراتور یکی‌یکی با تامین‌کنندگان تماس می‌گیرد و نرخ می‌گیرد
     ↓
نرخ‌ها دستی در سایت ثبت می‌شوند
     ↓
پیش‌فاکتور و قرارداد به صورت کاغذی/دستی
     ↓
بسیاری از Leadها پیگیری نمی‌شوند → مشتری از دست می‌رود
```

### کانال‌های ورودی مشتری (فعلی — بدون سیستم)

| کانال | وضعیت فعلی | مشکل |
|-------|-----------|------|
| شبکه‌های اجتماعی (اینستاگرام، لینکدین، تلگرام) | پیام دستی، بدون CRM | Lead گم می‌شود |
| معرفی دوستان / مشتریان | شفاهی، بدون ردیابی | پاداش معرف ثبت نمی‌شود |
| نمایشگاه / رویداد | کارت ویزیت / یادداشت | پیگیری بعد از نمایشگاه قطع |
| تماس تلفنی | اپراتور یادداشت می‌کند | پراکنده، بدون SLA |
| وب‌سایت | فرم تماس (اگر هست) | بدون پیگیری خودکار |

### نقاط درد (Pain Points) در فرآیند فعلی

| مرحله | مشکل | زمان تلف‌شده |
|-------|------|-------------|
| جذب Lead | بدون CRM، Lead گم می‌شود | — |
| ثبت درخواست | فرم پیچیده، بدون نرخ فوری | ۱۰-۳۰ دقیقه |
| تماس با Provider | وابسته به اپراتور، تماس دستی | ۲-۴۸ ساعت |
| جمع‌آوری نرخ | ثبت دستی توسط اپراتور، خطای انسانی | ۱-۳ روز |
| نمایش نرخ به مشتری | مشتری نمی‌تواند خودش ببیند | ۲۴-۷۲ ساعت |
| پیش‌فاکتور/قرارداد | کاغذی و دستی | ۱-۲ روز |
| انتخاب مشتری | بدون مقایسه شفاف | — |
| ردیابی | تماس تلفنی با راننده | — |

## 2.3 وضعیت هدف (To-Be)

```
کانال ورودی → Lead در CRM
     ↓
Export Sales: Inquiry → Quotation → LOI → PI → Contract
     ↓
Advance Payment (T/T + SWIFT) → تأیید مالی
     ↓
تدارکات/خرید از کارخانه (+ تولید در صورت نیاز)
     ↓
لجستیک: ۱۹ فرایند بارگیری و حمل
     ↓
Balance Payment (در صورت ۲۰/۸۰) → صدور مدارک حمل → تحویل
```
