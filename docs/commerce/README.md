[← بازگشت به فهرست اصلی](../README.md)

---

بخش **بازرگانی** پلتفرم SADRA شامل CRM (مدیریت مشتری)، SRM (مدیریت تامین‌کننده)، دستیار AI، کاتالوگ محصولات، تولید کارخانه‌ای و پیش‌فاکتور است.

> در حال حاضر فرآیندهای بازرگانی **دستی و کاغذی** هستند — هدف: **سیستمی‌سازی کامل**.
